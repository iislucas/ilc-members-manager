Orders & Subscriptions

Comprehensive documentation of the ILC Members Manager self-service orders and subscriptions system, Stripe billing integration, Video-on-Demand (VOD) streaming access control, Firestore data mirroring, and automated webhook fulfillment engine.

1. System Overview

The Orders and Subscriptions subsystem empowers I Liq Chuan members to manage their memberships, instructor licenses, Class Video Library passes, and standalone Video on Demand (VOD) purchases directly through the Me tab (/my-orders) and public video catalog (/videos). The architecture transitions manual and third-party renewals into an automated, self-service Stripe ecosystem while maintaining complete historical compatibility with legacy Squarespace orders and Google Sheets imports.

Member Self-Service Client
Dedicated /my-orders View

Real-time subscription cards with clear renewal dates, one-click cancellation/resumption, and instant receipt access.

Stripe Automation Backend
Cloud Functions & Webhooks

Idempotent webhook engine handling checkout fulfillment, automated annual/monthly renewals, and Customer Portal sessions.

Data Mirroring Firestore
Subcollections & Fast Summaries

Dual-layer storage: member document summary for synchronous client routing, plus private subcollection for granular order history.

VOD & Video Grants Streaming
Subscriptions & Standalone Buys

Dual access models: all-inclusive Class Video Library subscriptions plus standalone Stripe purchases creating durable VideoGrant records.

4. Expiry & Auto-Renew Semantics

Rather than storing a fragile boolean flag, auto-renewal status is represented by the explicit next renewal date. An empty string ('') indicates that auto-renewal is off, while the access expiration date remains intact.

Subscription State currentMembershipExpires membershipNextAutoRenewDate UI Badge & Status Label Available User Actions
Active Auto-Renewing 2027-05-15 2027-05-15 Active (Auto-Renewing)
Renews on May 15, 2027		 Cancel Auto-Renewal
Renewal Cancelled (In Grace) 2027-05-15 '' (empty) Active (Expires on date)
Valid through May 15, 2027 (Auto-renew off)		 Resume Auto-Renewal
Expired / Lapsed 2025-05-15 (Past) '' (empty) Expired
Expired on May 15, 2025		 Renew Membership (Links to /products)
Lifetime Member 9999-12-31 '' (empty) Lifetime Access

6. Webhook & Fulfillment Engine

The Cloud Function stripeWebhook listens for Stripe events, verifies signatures cryptographically, and delegates processing to modular handlers in functions/src/stripe-fulfillment.ts.

Stripe Webhook Event Trigger Scenario Automated System Action
checkout.session.completed Initial product purchase, first-time subscription, or standalone VOD purchase 1. Upserts /orders/{orderDocId} and mirrors to /members/{memberDocId}/orders/{orderDocId}.
2. Invokes appropriate product fulfillment handler in stripe-fulfillment.ts.
3. If membership / instructor / class video library: extends dates & records subscription.
4. If grading purchased: creates /gradings/{docId} and links to member.
5. If VOD purchased (category === 'vod' or metadata.videoId): creates VideoGrant in /members/{memberDocId}/videoGrants/{videoId} and mirrors to /video_grants/.
invoice.paid Scheduled recurring subscription billing cycle succeeded 1. Creates renewal order record in global orders and member subcollection.
2. Extends *Expires date by +1 period (month or year).
3. Sets *NextAutoRenewDate equal to new expiration date.
customer.subscription.updated Auto-renewal cancelled, resumed, or payment status changed 1. If cancel_at_period_end == true: clears *NextAutoRenewDate = '' while keeping access active.
2. If cancel_at_period_end == false: restores *NextAutoRenewDate = periodEnd.
customer.subscription.deleted Subscription cancelled immediately or billing period ended after cancellation 1. Records cancellation order row.
2. Clears active subscription IDs from member record.
3. Updates subscription map status to canceled.

8. Member Self-Service Dashboard Journey

Members navigate seamlessly from their home portal to their subscription control center.

1
Accessing the Portal

Member clicks the Orders card on the Me tab (/?tab=me). The router transitions to /my-orders with instant parent breadcrumb navigation.

2
Viewing Active Subscriptions & Renewal Status

The top section renders structured cards for Membership, Instructor License, Class Video Library, and custom Stripe plans. Each card clearly highlights whether auto-renewal is active, the exact renewal date, and the currency amount.

3
Browsing Historical Order Rows

The lower section displays a search-filtered chronological table of every order and invoice receipt across all platforms (Stripe, Squarespace, and Sheets). Clicking an order row expands line items and direct links to hosted receipts.

9. Auto-Renewal Cancellation Journey

Members can turn off automatic recurring charges without losing access to their current paid term.

1
Clicking "Cancel Auto-Renewal"

The member clicks the cancel button on an active subscription card. A confirmation dialog explains: "You will continue to have full access until your current expiration date (e.g. May 15, 2027)."

2
Callable Cloud Function Execution

cancelSubscriptionRenewal({ subscriptionId }) executes on Firebase Cloud Functions. It verifies ownership, updates Stripe with cancel_at_period_end: true, clears *NextAutoRenewDate = '', and returns the final expiration date.

3
Instant UI Feedback

The subscription card immediately transitions to "Active (Expires on date)" and the action button changes to "Resume Auto-Renewal".

10. Auto-Renewal Resumption Journey

If a member previously cancelled auto-renewal, they can reactivate automatic renewals at any time prior to the period expiration.

1
Clicking "Resume Auto-Renewal"

On a cancelled but currently active subscription card, the member clicks Resume Auto-Renewal.

2
Stripe Reactivation

resumeSubscriptionRenewal({ subscriptionId }) calls Stripe with cancel_at_period_end: false, restores *NextAutoRenewDate to the period end date, and persists the update in Firestore.

11. Stripe Hosted Customer Portal Journey

Allows members to securely update credit cards, change default payment methods, and download official PDF tax invoices.

1
Manage Payment Methods & Invoices

Member clicks "Manage Payment Methods & Invoices" in the page header.

2
Single-Use Session Generation

createCustomerPortalSession({ returnUrl }) creates an authenticated, short-lived Stripe Billing Portal session keyed to the member's stripeCustomerId with a return redirect back to /my-orders.

3
Stripe Hosted Management

The browser redirects to Stripe's secure portal. Upon completion or clicking "Return", the user is seamlessly routed back to the ILC portal.

12. Video on Demand (VOD) & Streaming Grants Flow

The platform integrates digital video monetization through two complementary access models: All-Access Class Video Library Subscriptions and Direct Single-Video Grants.

Class Video Library Subscription Recurring Sub

A recurring monthly or annual subscription (SubscriptionItemType.VideoLibrary) unlocking streaming access to the entire recorded class archive.

  • Managed via member.classVideoLibrarySubscription
  • Auto-extended on invoice.paid webhook
  • Cancels cleanly at period end while preserving access
Direct Video Purchases & Grants One-Time Grant

Standalone Stripe purchase (OrderItemCategory.Vod) or admin grant providing permanent or time-bound access to individual premium seminar recordings.

  • Persisted as VideoGrant in /members/{id}/videoGrants/{videoId}
  • Indexed globally in /video_grants/{memberDocId_videoId}
  • Permits non-members and non-subscribers to buy standalone videos
Playback Session Authorization Cascade (getVideoPlaybackSession)
Security Cascade 
User requests playback -> Client calls getVideoPlaybackSession({ videoId })
│
├── 1. Admin Verification: member.isAdmin == true?
│       └── YES -> Grant Full Streaming Access
│
├── 2. Public Tier: video.accessTiers.includes('public')?
│       └── YES -> Grant Full Streaming Access
│
├── 3. Individual Video Grant: /members/{id}/videoGrants/{videoId} exists & active?
│       └── YES -> Grant Full Streaming Access (Overrides membership/subscription requirements)
│
├── 4. Instructor License: accessTiers.includes('instructors_only') && instructorLicenseExpires >= today?
│       └── YES -> Grant Full Streaming Access
│
├── 5. Active Membership: accessTiers.includes('members_only') && currentMembershipExpires >= today?
│       └── YES -> Grant Full Streaming Access
│
├── 6. Class Video Subscriber: accessTiers.includes('class_video_subscribers') && classVideoLibrarySubscription?
│       └── YES -> Grant Full Streaming Access
│
└── 7. Denied -> Return { authorized: false, reason: 'purchase_required' | 'class_sub_required', priceCents, stripePriceId }
        └── Client displays dynamic CTA: "Unlock Video for $25" or "Subscribe to Class Library"
1
Catalog Browsing & Dynamic Entitlement Badging

Visitors browse the public catalog at /videos. The client compares the video's accessTiers against the user's active membership and grants: rendering "Watch Now" for authorized videos, "Included in Class Library" for subscribers, or "Unlock for $X" for buyable titles.

2
One-Click Checkout & Instant Webhook Grant

Clicking "Unlock" launches a Stripe Checkout session with metadata.videoId. Upon completion, stripeWebhook calls fulfillOrder(): instantiating a typed VideoGrant, recording the order in /members/{id}/orders, and immediately unlocking playback.

3
Adaptive HLS Playback & Position Synchronization

The Angular <app-video-player> streams multi-bitrate HLS (1080p, 720p, 480p, 360p) via Hls.js with thumbnail scrub previews. Every 5 seconds, watch progress is saved to /members/{id}/videoProgress/{videoId} for seamless "Continue Watching" across devices.

13. Security & Authorization Architecture

The system implements defense-in-depth across Firestore Security Rules and Cloud Function authorization layers.

Firestore Security Rules firestore.rules 
// Private member subcollections
match /members/{memberDocId}/orders/{orderDocId} {
  allow read: if isOrderOwner() || isAdmin();
  allow write: if isAdmin();
}

match /members/{memberDocId}/videoGrants/{grantId} {
  allow read: if isMemberOwner(memberDocId) || isAdmin();
  allow write: if isAdmin();
}

match /members/{memberDocId}/videoProgress/{videoId} {
  allow read, write: if isMemberOwner(memberDocId) || isAdmin();
}
Callable Function Ownership Guards stripe-subscriptions.ts & get-playback-session.ts 
// Playback session verification in Cloud Functions
const callerEmail = request.auth?.token.email;
const member = await getMemberByEmail(callerEmail, db);

// Verify explicit grant in member subcollection
const grantSnap = await db
  .collection('members')
  .doc(member.docId)
  .collection('videoGrants')
  .doc(video.docId)
  .get();

if (grantSnap.exists) {
  return { authorized: true, manifestUrl: video.manifestUrl };
}
