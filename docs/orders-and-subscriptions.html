1. System Overview

The ILC Members Manager is a modern member-facing web portal and administrative ecosystem for the I Liq Chuan martial arts community. It transitions manual membership renewals, instructor license verifications, grading candidate evaluations, and video streaming access into a fully automated, self-service platform backed by Firebase Cloud Firestore, Firebase Cloud Storage, Firebase Cloud Functions, and the Stripe Billing Platform.

2. Firestore Data Model & Collection Hierarchy

The platform's database architecture in Cloud Firestore is divided into top-level collections for primary organizational entities, private subcollections for member-scoped data (orders, video grants, watch progress, notifications), and cached subcollections for instructors and schools that enable fast query execution without expensive multi-collection joins.

Conventions: Document IDs (docId) are Firestore metadata and are never stored inside the document body; they are injected on read. All timestamps are normalized into ISO 8601 UTC strings on read, while non-admin writes enforce lastUpdated == request.time via Firestore Security Rules.

5. Expiry & Auto-Renew Semantics

Rather than relying on a fragile boolean flag, renewal states are governed deterministically by the explicit next renewal date. When a member cancels auto-renewal, the access expiration date remains intact while *NextAutoRenewDate is set to an empty string ('').

Renewal Cancelled (In Grace) 2027-05-15 '' (empty) Active (Expires on date)

7. Webhook & Fulfillment Engine

The Cloud Function stripeWebhook is an HTTP-triggered endpoint that cryptographically verifies the Stripe HMAC signature and routes events to modular handlers in functions/src/stripe-fulfillment.ts. Every webhook execution is designed to be completely idempotent, preventing double-billing or multiple membership extensions.

Stripe Webhook Event Trigger Scenario Automated System Action
checkout.session.completed Initial product purchase, first-time subscription, or standalone VOD purchase. 1. Upserts /orders/{orderDocId} and mirrors to /members/{memberDocId}/orders/{orderDocId}.
2. Invokes appropriate product fulfillment handler in stripe-fulfillment.ts.
3. If membership / instructor / class video library: extends dates & records subscription.
4. If standalone VOD: writes durable VideoGrant to /members/{id}/videoGrants/{videoId}.
5. If grading: instantiates a new Grading document in /gradings/{docId}.
invoice.paid Automatic annual or monthly subscription renewal payment succeeds. 1. Creates a new renewal MemberOrder in the member's subcollection.
2. Advances currentMembershipExpires or classVideoLibraryExpirationDate by 1 full period.
3. Synchronizes *NextAutoRenewDate with Stripe's current_period_end.
4. Syncs the updated expiry date to /acl/{email} for instant security rules enforcement.
customer.subscription.updated Member cancels/resumes auto-renewal in Stripe Portal, or payment method fails. 1. If cancel_at_period_end == true: clears *NextAutoRenewDate = '' (retaining access expiration).
2. If cancel_at_period_end == false: restores *NextAutoRenewDate = current_period_end.
3. Updates the cached MemberSubscriptionItem inside member.stripeSubscriptions.
customer.subscription.deleted Subscription lifecycle ends (grace period concludes after cancellation). 1. Clears membershipSubscriptionId or classVideoLibrarySubscriptionId on the member.
2. Marks the subscription record as SubscriptionStatus.Canceled.

9. Member Self-Service Dashboard Journey

Members navigate seamlessly from their home portal to their subscription control center.

1
Accessing the Portal

Member clicks the Orders card on the Me tab (/?tab=me). The router transitions to /my-orders with instant parent breadcrumb navigation.

2
Viewing Active Subscriptions & Renewal Status

The top section renders structured cards for Membership, Instructor License, Class Video Library, and custom Stripe plans. Each card clearly highlights whether auto-renewal is active, the exact renewal date, and the currency amount.

3
Browsing Historical Order Rows

The lower section displays a search-filtered chronological table of every order and invoice receipt across all platforms (Stripe, Squarespace, and Sheets). Clicking an order row expands line items and direct links to hosted receipts.

10. Auto-Renewal Cancellation Journey

Members can turn off automatic recurring charges without losing access to their current paid term.

1
Clicking "Cancel Auto-Renewal"

The member clicks the cancel button on an active subscription card. A confirmation dialog explains: "You will continue to have full access until your current expiration date (e.g. May 15, 2027)."

2
Callable Cloud Function Execution

cancelSubscriptionRenewal({ subscriptionId }) executes on Firebase Cloud Functions. It verifies ownership, updates Stripe with cancel_at_period_end: true, clears *NextAutoRenewDate = '', and returns the final expiration date.

3
Instant UI Feedback

The subscription card immediately transitions to "Active (Expires on date)" and the action button changes to "Resume Auto-Renewal".

11. Auto-Renewal Resumption Journey

If a member previously cancelled auto-renewal, they can reactivate automatic renewals at any time prior to period expiration.

1
Clicking "Resume Auto-Renewal"

On a cancelled but currently active subscription card, the member clicks Resume Auto-Renewal.

2
Stripe Reactivation

resumeSubscriptionRenewal({ subscriptionId }) calls Stripe with cancel_at_period_end: false, restores *NextAutoRenewDate to the period end date, and persists the update in Firestore.

14. Comprehensive Security & Authorization Model

The system implements a unified Defense-in-Depth Security Model spanning Cloud Firestore Security Rules, Cloud Storage Security Rules, and server-side Cloud Function authorization guards.

Core Principle — Default-Deny & Centralized ACL Resolution: Every operation defaults to false. Access decisions are resolved in O(1) time by looking up the authenticated user's login email against /databases/(default)/documents/acl/$(request.auth.token.email). Cloud Function triggers eagerly synchronize active roles, school manager IDs, instructor licenses, and expiration dates into this document, completely avoiding expensive multi-document recursive queries during rule evaluation.

Cloud Storage Security Rules storage.rules 
// Resource tier access based on ACL expiration dates
function hasActiveMembership() {
  let email = request.auth.token.email;
  let aclData = firestore.get(/databases/(default)/documents/acl/$(email)).data;
  let expires = aclData.membershipExpires;
  return email != null && expires >= todayStr();
}

match /resources/members/{fileId} {
  allow read: if request.auth != null && (isAdmin() || hasActiveMembership());
  allow write: if isAdmin();
}

match /members/{memberDocId}/materials/{material=**} {
  allow read, write: if isAdmin() || (
    request.auth != null && memberDocId in getUserMemberDocIds()
  );
}
