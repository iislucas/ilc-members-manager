ILC Members Portal Architecture

The official web platform and member portal for the international Zhong Xin Dao I Liq Chuan martial arts community. A high-performance, real-time Progressive Web App (PWA) managing memberships, international gradings, certified schools, instructor profiles, workshop events, Video-on-Demand (VOD) streaming, and unified multi-channel store orders.

🌐 Practitioners & Members Self-Service

Digital passbook tracking student grades, membership status, seminar signups, event proposals, notifications, and subscription renewals.

🥋 Instructors & Schools Community

Student roster management, grading requests acceptance and evaluations, school listings, class schedules, and teaching materials uploads.

🛡️ Headquarters (HQ) Admin Global Control

Unified control plane for global member records, manual order reconciliation, Stripe product syncing, VOD transcoding curation, and backups.

User Roles & Access Control Matrix

The system uses an explicit Role-Based Access Control (RBAC) model cached in Firestore /acl/{email} and evaluated in Firestore Security Rules:

Role Who Key Capabilities Permissions in Rules
Public / Visitor Unauthenticated viewers Browse public instructors, view upcoming workshops & school calendars, watch public VOD videos, purchase direct items. Read-only for public collections (/events, /schools, /instructors, /videos[isPublished=true]).
Registered User Authenticated via Email / Google Create member application profile, complete profile details, view personal dashboard. Read/write own /members/{ownId} and /acl/{ownEmail}.
Active Member Current paid member (Annual / Life) Access digital passbook, read members-only articles & videos, request gradings, propose workshops, receive push notifications. Read /members-area content, read/write own /gradings, write /events proposals.
Certified Instructor Licensed ILC Instructor View student rosters, review/accept grading requests, evaluate student levels, post teaching materials, manage public profile bio. Read/update students in /instructors/{id}/members, manage linked /gradings.
School Manager Owner or Manager of an ILC School Manage school address, timetable, and view members belonging to the school branch. Read/update school profile and members in /schools/{id}/members.
Event Manager Organizer of an IlcEvent Edit workshop schedule, venue, contacts, and manage gradings conducted at that workshop. Derived dynamically via isGradingEventManager() in Firestore rules.
HQ Admin Global ILC Administrators Full system control: approve gradings, trigger video transcoding, reconcile orders, export backups, manage settings. Bypasses restrictions via isAdmin() in security rules.

Firestore Collections Architecture

The primary Firestore root collections and domain types defined in functions/src/data-model.ts:

📁 /members/{docId} Member

Primary member records containing full profile, membership type (Annual, Life), expiration dates, license statuses, and linked IDs.

emails: string[], memberId: string, name: string, studentLevel: number
🥋 /instructors/{docId} InstructorPublicData

Public instructor registry mirrored automatically from the member document. Displayed in public find-an-instructor tools.

instructorId: string, name: string, level: string, bio: string, location: string
🏫 /schools/{docId} School

Official school branches worldwide with geographic coordinates, owner instructor IDs, manager emails, and class schedules.

schoolId: string, schoolName: string, ownerInstructorId: string, lat: number
⛰️ /gradings/{docId} Grading

Assessment requests tracking the 3-step workflow (Requested → Awaiting Grading → Finalized Passed/Not Passed) and examiner notes.

studentMemberDocId: string, level: string, status: GradingStatus, gradingEventDocId
📅 /events/{docId} IlcEvent

Workshops, seminars, and training camps. Synced from Google Calendar or proposed directly by members and approved by HQ.

title: string, startDate: string, ownerDocId: string, managerDocIds: string[]
📦 /orders/{docId} Order

Multi-channel unified order ledger aggregating Stripe checkout sessions, Squarespace store orders, and legacy Google Sheets imports.

orderNumber: string, amountTotal: number, paymentStatus: string, lineItems: []
🎬 /videos/{docId} VideoItem

Video on Demand streaming catalog. Contains HLS master manifest URLs, resolutions, duration, pricing, categories, and tags.

accessTier: VodAccessTier, vodStatus: VodStatus, manifestUrl: string, tags: []
🔑 /acl/{email} ACL

Fast permission cache indexed by normalized lowercase email. Enables rapid security rule execution without expensive sub-queries.

isAdmin: boolean, memberDocIds: string[], schoolDocIds: string[]

Cloud Functions & Microservices

Node.js 22 serverless Cloud Functions deployed in functions/src/:

⚡ HTTP & Callable Endpoints 2nd Gen onCall
  • checkEmailStatus: Pre-auth email check for account lookup.
  • getUserDetails: Hydrates full member session and ACL tokens.
  • listStripeProducts: Caches active Stripe products & prices.
  • createStripeCheckoutSession: Generates hosted checkout URLs.
  • createCustomerPortalSession: Self-service billing management.
  • getVideoPlaybackSession: Gated entitlement validator for VOD.
  • transcodeVideoForVod: Initiates GCP Transcoder encoding.
  • deleteVideoFromCatalog: Cleans up VOD manifests and storage.
  • getResourceDownloadUrl: Generates signed temporary storage URLs.
  • socialPreview: Dynamic OpenGraph image preview generator.
🔄 Firestore Document Triggers onDocumentWritten
  • onMemberCreated: Auto-provisions Member ID and initializes ACL.
  • onMemberUpdate: Mirrors member data to instructor & school subcollections, sends welcome emails, and updates ACL.
  • onSchoolUpdate: Syncs school manager emails into ACL cache.
  • onGradingUpdate: Increments student level on Pass, mirrors grading to examiners, sends notifications.
  • stripeWebhook: Listens for checkout.session.completed, invoice.paid, and triggers fulfillStripeOrder.
  • backupScheduled: Nightly backup dumping all collections to GCS.

Development Setup & Quickstart

The project strictly uses pnpm (never npm or npx) and runs on Angular 20+ and Node.js 22:

# 1. Install dependencies
pnpm install
cd functions && pnpm install && cd ..

# 2. Build Cloud Functions TypeScript
pnpm build:functions

# 3. Start local development server (Angular on http://localhost:4200)
pnpm start

# 4. Start Firebase Emulators (Auth 9099, Firestore 8080, Functions 5001, Storage 9199, UI 4000)
pnpm emulator:start

# 5. Run full test suites
pnpm test              # Vitest Angular Unit Tests
pnpm test:functions    # Cloud Functions Tests
pnpm test:rules        # Firestore Rules Tests in Emulator

Troubleshooting & Known Gotchas

⚠️ Backups: "Permission 'iam.serviceAccounts.signBlob' denied"

When calling listBackups, the Cloud Function requires the Service Account Token Creator (roles/iam.serviceAccountTokenCreator) IAM role to generate signed GCS download URLs.

ℹ️ Email Case Normalization

All login and member lookup queries normalize emails to lowercase (email.toLowerCase().trim()). Firestore /acl/{email} document IDs must always be stored in lowercase.
